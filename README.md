## 🚀 Proyectos

### 🤖 Robótica y dinámica

- **Dinámica computacional del mecanismo Theo Jansen:** estudio del mecanismo mediante formulación aumentada e implementación en Autodesk Inventor. Como línea futura, se plantea el estudio de mecanismos cuadrúpedos y multípedos.
- **Cuadrúpedo basado en el mecanismo de Chebyshev:** desarrollo conceptual de un robot cuadrúpedo empleando el mecanismo de Chebyshev.
- **SLAM en LEGO EV3:** exploración de la integración de técnicas de SLAM en un LEGO EV3 utilizando una Raspberry Pi 5.

### 🎛️ Control

- **Ball and Beam:** implementación de controladores PID y espacio de estados (SS), con futuras pruebas de técnicas de control adicionales.
- **Aerobalancín:** desarrollo e implementación de controladores LQR, control deslizante y MRAC (control adaptativo por modelo de referencia).

### 🧪 Investigación — ARGES (En Desarrollo)

- **Caracterización de materiales depositados mediante WAAM-GMAW-FCAW:** estudio de las propiedades de materiales fabricados mediante manufactura aditiva por arco eléctrico.
- **Evaluación automática de ensayos no destructivos:** desarrollo de modelos de Deep Learning para la evaluación automática de imágenes provenientes de técnicas como radiografía (RT) y líquidos penetrantes (PT).
- **Máquina automática de revelado y fijado:** desarrollo de una máquina para automatizar el proceso de revelado y fijado de películas radiográficas.

### 🎮 Otros proyectos
